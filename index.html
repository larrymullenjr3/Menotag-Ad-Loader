MONETAG TOOL

Monetag Ad Loader

Load rewarded-interstitial advertisements using a zone ID directly in the website URL.

How to Use

1 Get your Monetag zone ID

Find the zone ID in your Monetag account.

2 Add the zone ID to the website URL

Append your numeric zone ID to the website address.

https://monetag-ad-loader.vercel.app/12116377
3 Open the generated URL

The page loads the SDK for that zone and requests a rewarded-interstitial advertisement.

About the Loader

The loader uses the zone ID supplied in the URL. You can use other numeric zone IDs without changing this website's code. Ad availability depends on the SDK, zone configuration, browser and available inventory.
